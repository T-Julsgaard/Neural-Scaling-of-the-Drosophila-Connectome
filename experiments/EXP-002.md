## Hypothesis and scope

H2: feedback-dependent learning improves early reversal relative to a reward-only rule on a fixed larval-derived representation. Minimum useful primary difference: **0.05 preferred-choice probability**. Alternatives: a generic prediction-error rule explains the entire effect; representation overlap dominates the result; reward-only learning is already sufficient; or gains in reversal cost retention.

This tests learning-rule headroom, not that all topology-preserving optimization has been exhausted. The [Bennett model](https://www.nature.com/articles/s41467-021-22592-4) is close prior work; [compensatory-variability work](https://pubmed.ncbi.nlm.nih.gov/34845010/) and [Xie's perturbation study](https://arxiv.org/abs/2509.19351) limit novelty. A positive result validates a platform component and motivates the next experiment; the mechanism alone is not new.

## Circuit and exact learning rules

Use D05's 40 PN→73 mature KC projection, identified by the data audit. KC encoding and the two synthetic valence outputs follow the shared benchmark. All connectivity remains fixed. For a cue activity vector s, compute `q=(w_plus-w_minus) dot s`. For the chosen cue, receive r∈{−1,+1}. All updates use pre-update weights and are applied simultaneously:

| Arm | Update |
|---|---|
| Frozen | No update; q remains zero; equal cue probabilities. Diagnostic only |
| Reward-only | `w_plus <- max(0,w_plus + eta*s*r)`; `w_minus <- max(0,w_minus - eta*s*r)` |
| Feedback / Bennett mixed-valence eq8 | `d_plus=max(0,gamma*sum(s)-q+r)`; `d_minus=max(0,gamma*sum(s)+q-r)`; `w_plus <- max(0,w_plus+eta*s*(d_plus-d_minus))`; `w_minus <- max(0,w_minus+eta*s*(d_minus-d_plus))` |
| Generic delta | `delta=r-q`; `w_plus <- max(0,w_plus+eta*s*delta)`; `w_minus <- max(0,w_minus-eta*s*delta)` |

Fix gamma=0.1 for the feedback arm; this is a project assay setting, not a claimed uniquely physiological value. All arms share initial weights 0.1, coding sum(s)=10 and softmax temperature search. In the regime where both d values are positive, feedback's difference equals `2*(r-q)`. Therefore, it can be algebraically equivalent to a delta rule with a rescaled learning rate. **Report the fraction of updates in that regime and check equivalence after rate matching. Do not interpret equivalent rules as independent biological mechanisms.** The primary contrast is feedback versus reward-only; the generic control diagnoses whether a biological label adds explanatory value.

For the rate-matching validation, supply identical activities/rewards and compare feedback eta=0.001 with delta eta=0.002 on steps where both d values are nonnegative and their difference equals2(r−q). Expected simultaneous weight updates agree within10^-10. This is an analytic validation fixture, not an extra confirmation hyperparameter search.

Search eta∈{0.0001,0.001,0.01} and T∈{0.1,0.2,0.5}: nine configurations per adaptive arm. Frozen may share each T for implementation consistency, but remains a single diagnostic outcome. Select settings on development blocks by the mean of acquisition score, primary reversal score and final retention-probe probability, weighted equally. Tie within 10^-6: smaller eta, then larger T. Freeze one setting per arm; no graph/feature tuning. Include a prespecified fixed-setting trace at eta=0.001,T=0.2 for mechanistic comparison, distinct from the tuned primary comparison.

## Confirmation and interpretation

Use 20 blocks ×20 episodes ×384 trials per adaptive arm (153,600 learning trials/arm), with development using ten independent blocks. Average within block before paired uncertainty analysis. Primary: feedback minus reward-only early-reversal score with 98.33% interval and +0.05 minimum. Secondary: feedback versus delta, acquisition, return adaptation, retention, noise robustness, direct-PN baseline and learning curves.

Continuation to growth requires a validated adaptive learner, no unresolved numerical failure, and a usable assay: the selected learner's lower 95% acquisition interval >0.65, while at least one adaptation/retention metric remains below 0.90. If all learners are at ceiling, increase task interference through a documented development-only protocol revision before confirmation. If all are near chance, inspect feature overlap and update dynamics rather than enlarging a broken assay.

Support H2 when the primary lower bound exceeds +0.05, with acquisition noninferiority secondary margin −0.02. If delta matches feedback within ±0.02, retain the simpler explanatory account: prediction-error learning, not a uniquely biological algorithm. If the primary upper bound is below +0.05, rule out a practically useful feedback advantage in this assay, not all plasticity benefits. A reversal gain with substantial retention loss is a tradeoff, and must be shown as such.
