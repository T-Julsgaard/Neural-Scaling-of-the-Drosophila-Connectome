# EXP-003 — Does structured population growth buy useful adaptive capacity?

Status: **proposed; not run**. Branch B3, with B5-inspired statistical growth rules. Depends on a validated learning assay from EXP-002, not on a positive feedback-versus-reward-only result. All task and analysis definitions are inherited from [BENCHMARK_SPEC.md](../BENCHMARK_SPEC.md).

## Two separate hypotheses

H3-scale: increasing mature KC population size improves the adaptive capability profile under at least one specified growth rule.

H3-organization (primary): at N=110, conditionally sampled growth beats a signed-positive degree-matched growth null by **0.05 early-reversal choice probability**, with the same number of features, edges, output weights, learning exposures and tuning opportunities. This is a test of a statistical wiring prior, **not a literal developmental mechanism**. Negative H3-organization does not refute H3-scale.

Closest work: [Elkahlah developmental compensation](https://elifesciences.org/articles/52278), [Ellis comparative architecture](https://www.nature.com/articles/s41467-024-48839-4), [Litwin-Kumar expansion-layer theory](https://pmc.ncbi.nlm.nih.gov/articles/PMC5379477/), [Abdelrahman compensation](https://pubmed.ncbi.nlm.nih.gov/34845010/), [Xie structural perturbation](https://arxiv.org/abs/2509.19351). No equivalent to this exact combined protocol was located in the documented search; these papers already establish its constituent ideas.

## Starting model and sizes

Start with the same 40 PN→73 mature KC anatomical projection and two synthetic outputs. Exclude all 37 young KCs at every size. Add mature-feature units only; no inferred developmental maturation of young cells. Sizes are `round_half_up(73*s)` for s∈{1,1.1,1.25,1.5,2}: **73,80,91,110,146**. Store realized ratios. Existing PN→KC columns never change in the main growth arms. PNs remain 40 and output units remain two.

Use a single learning mechanism across all growth arms: choose between feedback and generic delta using EXP-002 development score; tie within 0.02 chooses generic delta. Do not use EXP-002 confirmation outcomes for this choice. Choose eta and T jointly across all growth arms and sizes using a fresh EXP-003 development stage and the nine-point grid in EXP-002, maximizing equal-weight mean development score across sizes/arms. Freeze one shared eta/T for confirmation. This prevents an architecture-specific tuning advantage. Also report the fixed EXP-002 setting as an exploratory sensitivity trace on validation/development only.

## Reproducible growth algorithms

Classify the 73 mature donor cells by published claw label (1 through 6). To allocate m=N−73 added cells, distribute m across strata proportional to their native counts using largest remainders, tie by lower claw number. Within each stratum sample donors uniformly with replacement. Give added nodes IDs `grown:<block>:<replicate>:<size>:<ordinal>` and record donor index, stratum, new partners and raw weights. Use shared donor selections across matched arms. At N=73 all main arms reduce to the same graph and must yield identical traces under paired streams.

1. **Clone:** duplicate the donor's entire raw PN input column. Exact feature duplicates are intentional. This controls extra output parameters without guaranteed extra feature diversity.
2. **Conditioned resampling (structured):** for each stratum, compute each PN's frequency of positive connections to native KCs in that stratum, add pseudocount 1, normalize. A new cell retains its donor's number d of distinct positive PN partners and multiset of d positive contact counts. Sample d distinct PNs sequentially without replacement from the stratum distribution, renormalizing after each draw. Assign a random permutation of the donor counts to them. The claw label indexes a statistical distribution; d comes from the actual selected matrix and need not equal the label.
3. **Uniform resampling:** same donors, d and count multiset, but select PN partners uniformly without replacement. Matches N, added E, target contact sums and output parameters to structured growth; PN out-degrees are not matched.
4. **Degree-matched null (primary comparator):** take only the added PN→KC edges from the structured arm. Repeatedly swap `(p1→k1,p2→k2)` to `(p1→k2,p2→k1)` if p1≠p2,k1≠k2 and neither new edge exists. Move weights with their target cells so each new KC keeps its input-count multiset. Preserve existing columns exactly. Attempt up to 100*E_added proposals for 10*E_added successful swaps. This preserves added PN out-degree, new KC in-degree and per-KC contact sums, while changing which partners co-occur. Raw PN weighted strengths are not matched. Record overlap and successful swaps. If fewer than E_added successful swaps, report mixing failure and do not interpret the organization contrast at that size; revise null construction before a new confirmation campaign.

No edges are learned or pruned during episodes. Target-normalize each column after growth, then apply the same k-winner activity rule with k=round_half_up(0.05*N). Integer k steps can themselves affect performance; include a **fixed-k=4** secondary confirmation assay at N=73 and110 for structured/null/clone. It matches active-unit count rather than activity fraction. Both use sum(s)=10. A growth claim must state which sparsity condition produced it.

## Resource controls and parameter bottleneck

The main comparison matches each grown size across rules, not all sizes to the 73-cell baseline. Output weights grow from 146 to 2N; fixed projection edges and inference work grow too. These are real costs, not confounds to hide. No assertion is made that N, E, parameters, runtime and energy are all simultaneously matched.

At N=73 and110 add a **32-feature fixed readout bottleneck** secondary assay for structured and its degree null. Construct a nonlearned 32×N projection by assigning each KC to `matrix_index mod 32` for native cells and `added_ordinal mod 32` for grown cells; weight each nonempty bin by the reciprocal of its member count. This arbitrary deterministic adapter is paired across arms and must be counted as computation. Apply to s and renormalize its output to sum 10 (if zero, record failure). Train the same two valence outputs on these 32 features: 64 trainable weights at either size. Report both full and bottleneck readout results; bottleneck information loss means it is a diagnostic, not a perfect resource-matching solution.

Additional exploratory baseline: uniform-resample all 73 native columns using their original distinct-partner counts and count multisets, then apply uniform growth. This tests whether keeping the native base is itself essential. It has the same configuration budget and is not included in the primary ranking or shared-parameter selection.

## Validation and confirmation

R03: every arm must satisfy its declared degree/count invariants; N=73 traces must coincide; zero input columns are prohibited; donor lineage must be recoverable; all prototypes and action/outcome streams must be paired across arms. Confirm frozen probes and checkpoint/resumption through EXP-002 validations. Do not enlarge a model with unresolved update-rule errors.

20 independent confirmation blocks, three nested graph-growth replicates per block/size/arm, 20 episodes per replicate. Native baseline is simulated once per block and reused, not counted as three independent results. Primary contrast averages the three graph replicates within each block at N=110, full readout, proportional sparsity, then uses the shared 98.33% interval. All other sizes, fixed-k and bottleneck results are secondary with 95% intervals.

Report the capability profile against N,E,contact totals,output weights and measured time. Primary practical minimum +0.05; acquisition secondary noninferiority margin −0.02. For H3-scale report each growth curve and paired change from73 to110 and146. Do not fit a claimed universal power law to five points. Saturation, monotonicity violations and changes in per-cell participation are informative. Quantify effective feature rank and exact duplicate columns to diagnose why cloning or resampling behaves differently.

Continue to adult circuit validation if a useful scale effect persists across both reversal and retention/robustness checks without a major acquisition loss, regardless of whether the organization effect is positive. Prefer structured growth only if its primary contrast meets the minimum and diagnostics do not reduce the result to a readout/sparsity artifact. If the upper primary interval is below +0.05, deprioritize this biological prior. If all curves are flat with adequate precision, stop population growth in this assay and consider sparse intervention, richer sensory tasks or module coupling. If intervals are wide, classify the result as inconclusive and justify any new sample budget prospectively.

## Resource envelope

Unmeasured estimate: 4–7 implementation days beyond the validated EXP-002 runner; 1–7 CPU-days; <4 GB RAM and <10 GB retained metrics/checkpoints. Main confirmation is at most 20 blocks ×3 graphs ×5 sizes ×4 arms ×20 episodes ×384 trials ≈9.22 million trials before baseline reuse, plus secondary assays. Maximum projection is40×146; raw matrices are tiny compared with trace storage. Estimate runtime from measured blocks at N=73 and146 before launch. No whole-brain training, body simulation or GPU is required. Full-state recording for every trial is prohibited by the default storage contract.
