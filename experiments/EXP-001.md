# EXP-001 — Does wiring affect capacity after normalization and readout control?

Status: **proposed; no model built or result measured**. Branch B4 (intrinsic capacity), with B1 dynamics controls. Read [BENCHMARK_SPEC.md](../BENCHMARK_SPEC.md) first. Primary scientific value is validating a discriminating assay. It does not test enlargement or establish a new reservoir architecture.

## Hypothesis and alternatives

H1: the native visual wiring supports a higher mean recoverable delayed/nonlinear-input score than signed-degree-preserving rewires under identical input/output access and contraction normalization. Minimum useful difference: **0.02 mean held-out R²** across the 48 specified targets. Alternatives: degree/weight distribution suffices; advantage depends on normalization; input/output placement creates it; or the chosen capacity battery favors random wiring.

Closest work: [Dambre](https://www.nature.com/articles/srep00514), [conn2res](https://www.nature.com/articles/s41467-024-44900-4), [Morra](https://arxiv.org/abs/2201.09359), [Costi](https://www.mdpi.com/2313-7673/10/5/341). This is an adaptation of known methods. It is not a physiological reproduction of [Lappalainen](https://www.nature.com/articles/s41586-024-07939-3).

## Input and circuit

Use D06 wiring at flyvis commit `92b3845cc426dd309a1a0e1b3890156c42e14021`, file `flyvis/connectome/fib25-fib19_v2.2.json`. Instantiate the source constructor's hexagonal tiling at `extent=1,n_syn_fill=0`; no gap interpolation. Preserve the original node ordering and IDs `(cell_type,u,v)`. There are at most 64×7=448 units; exact N/E must be recorded from the constructor. Preserve self-loops, if present, identically in every arm. Sum duplicate same-sign ordered pairs; if opposing signs occur on the same pair, stop and explicitly revise the multiedge policy before any confirmation.

Build `A[target,source]=sign*estimated_contact_count`. Do not use learned synaptic strengths, lambda/certainty as efficacy multipliers, or cell-type parameter sharing. Input is a scalar applied with coefficient +1 to R1–R8 at `(0,0)` and zero elsewhere. Fixed primary readout: the first 32 central-column nodes in lexicographic cell-type order whose type is in the wiring file's output_units list. Assert all 32 exist; preserve identical IDs across arms. An all-node readout is secondary and changes the parameter budget.

## Dynamics and fitting

Use float64, zero initial state, no recurrent learning:

`x[t+1]=(1-a)*x[t]+a*tanh(W@x[t]+b*u[t])`.

Primary normalization: `W=g*A/sigma_max(A)` using the largest singular value (dense SVD is acceptable at this size). Search g∈{0.5,0.8,0.95}, a∈{0.2,0.5,1.0}, input coefficient b on the selected nodes ∈{0.1,0.5}: 18 settings. Because tanh is 1-Lipschitz and g<1, this map is contractive in the Euclidean norm. Spectral radius <1 alone is not used as a global guarantee.

Diagnostic normalization: fix g=0.8,a=0.5,b=0.5 and rescale each graph by its own spectral radius to 0.8; if radius≤10^-12, mark that diagnostic undefined. Record singular norm, radius, saturation fraction and state variance. This deliberately tests sensitivity to a common normalization convention; it is not the primary arm-selection rule.

For each stream draw u iid Uniform[-1,1]. Reset state between train/development/test streams. Each stream has 512 washout steps plus 4,096 retained samples; align feature x[t+1] with targets based on inputs through u[t]. Target set: 32 linear delays `sqrt(3)*u[t-d]` for d=1…32, plus 16 products `3*u[t-d]*u[t-d-1]` for d=1…16. Generate sufficient preceding inputs for all delays before the retained region. These orthogonal targets sample capacity; they do not exhaust it.

Fit an intercept and ridge readout separately for each target, using only train-state means/scales. Set zero-variance feature scale to 1. Ridge objective is mean squared error + λ*sum(nonintercept_coefficients²), λ∈{10^-8,10^-6,10^-4,10^-2,1}. Use QR/SVD or a stable solve, not explicit inversion. Choose a common λ and dynamics setting per architecture arm from mean development score across development blocks; tie-break within 10^-6 by larger λ, smaller g, smaller a, smaller b. Development blocks each have independent fit and score streams. Confirmation blocks each fit readout weights on their own fresh 4,096-point training stream using these frozen hyperparameters, then evaluate on an independent test stream; this is permitted supervised readout fitting, not test adaptation.

## Arms and matching

1. Native A.
2. Signed-degree null: within each sign, double-edge swap `(i→j,k→l)` to `(i→l,k→j)` with distinct endpoints, no duplicate/new self-loop; keep native self-loops frozen. This preserves signed in/out degrees. Move magnitudes with sources. Complete 10*E successful swaps or stop at 100*E proposals; report actual swaps and edge overlap. If fewer than E successful swaps, mark null-mixing validation failed and do not interpret primary contrast.
3. Weight shuffle: preserve topology/sign and independently permute magnitudes within sign classes.
4. Same-N/E random graph: preserve self-loops and positive/negative edge totals, uniformly sample other ordered pairs without replacement, assign original signed magnitude multiset randomly. Degrees are not matched.

Generate three graphs per null arm per block; native is one graph. Match N, E, sign totals, magnitude multiset, input vector, readout dimension, stream lengths and hyperparameter-search opportunities. Signed strengths per neuron, spatial layout, singular spectrum, and physical wiring cost are not all matched. Report them. Do not hold native parameter-sharing metadata fixed in null graphs because no sharing is used in this assay.

## Validation before interpretation

R01 in [REPRODUCTIONS.md](../REPRODUCTIONS.md): compare an independent graph parser against the pinned constructor; compare the recurrence against conn2res or an independent reference on a 4-node fixture; verify a supplied exact delay-tap feature baseline gives R²>0.99 and shuffled targets give no reproducible positive performance. Check two initial states converge under primary normalization. Validate that nulls preserve their declared invariants. These are implementation validations, not reproductions of published effect sizes.

## Analysis and decisions

20 independent confirmation blocks, three nested nulls each, common seeds/splits and bootstrap contract. Score each target with `1-SSE/sum((y-mean(y_test))²)`; retain negative R². Primary is the arithmetic mean of 48 scores with 32-node readout. Also show separate linear/product sums, delay curves, all-node readout, and normalization diagnostic. The estimated capacity sum is finite-sample/task-limited, not a universal bound.

Support H1 only if the 98.33% paired interval exceeds +0.02. If upper bound<0.02, deprioritize strong architecture-specific claims for this assay; if all arms fail validation or learn little, repair the measurement or change task family before interpreting topology. If the effect reverses under the diagnostic normalization or disappears with controlled readout access, investigate that mechanism before growth. A successful result warrants replication at extent=2 or an adult circuit; neither is part of this candidate's confirmation run.

## Resource and implementation envelope

Unmeasured planning estimate: 3–6 focused implementation days, 2–7 CPU-days for the complete grid/confirmation/diagnostics, <8 GB peak RAM and <5 GB retained output with sequential graphs. A 4,096×448 float64 state matrix is ~14.7 MB; one dense 448² matrix is ~1.6 MB. The upper compute envelope is approximately 18 settings × (10 development +20 confirmation blocks) ×10 graphs ×12,800 steps, before reused trajectories and diagnostic runs. Recurrent work scales as E per step; fit work also depends on readout dimension. Freeze hyperparameters before confirmation so its trajectory count should fall well below this deliberately conservative envelope. Measure a validation block on the target workstation; do not promise these times or use the session GPU as a sizing assumption.
