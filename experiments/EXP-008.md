# EXP-008: adult projection validation

[Prospective protocol](EXP-008-protocol.md) defines the prediction, independent anatomy, transferred calibration procedure, baseline budgets, inference and branch gates. [Anatomy manifest](../results/exp008_anatomy/record.json) pins the public source archive, annotation commit, IDs and transformations. [Validation record](../research/exp008_validation.json) records nine preflight tests and exact full-block replay.

The experiment uses local Python 3.12.14 and NumPy 2.3.5. Use the Python executable saved in stage contracts, or an independently validated matching environment. Commands run from the repository root:

```powershell
python tools/fetch_transfer_data.py
python tools/run_transfer.py audit-development
python tools/run_transfer.py audit-confirmation
python tools/report_transfer.py
python tools/analyze_transfer_geometry.py
python tools/finalize_transfer_records.py
```

The fetch command verifies existing cached inputs or recovers the exact public files; it does not modify experimental results. The audits require the local NPZ checkpoints. Graph construction for a fresh, separate reproduction workspace is `python -m exp008.data`, followed by `python tools/run_transfer.py validate`, `development`, and `confirmation`. Preserve the completed workspace and its frozen contracts when starting an independent reproduction. Do not regenerate its calibration or alter its source files to append confirmation samples.

The run command checks frozen source, runtime, calibration and checkpoint hashes before resuming. Raw checkpoints and the 45 MB source archive are local and Git-ignored; compact contracts, selections, audits, results and provenance are retained in project records. Matplotlib is used only for figures and is separate from the neural runtime. Plotting can be skipped with `python tools/report_transfer.py --no-plot`.

This validates a prediction in an adult subcircuit within the same synthetic learning assay. It does not reproduce biological odor behavior or establish a general causal explanation.
