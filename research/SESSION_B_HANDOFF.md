## Current evidence and boundary

EXP-009 is a bounded adaptation using one supplied author-fitted model, with fresh task prototypes/labels/noise and validated response/learning/decision equations. It is not an exact Figure 4 reproduction. A successful gate permits a controlled bridge to **this supplied-parameter regime only**. Source and fitted file differ in excitation scale (4.5 in current script, 5 in saved file). No claim that the joint optimizer, twenty-model published ensemble or biological compensation was independently reproduced.

Preserve EXP-002–009 scientific files and all confirmation samples. Use a new experiment ID only after checking current records; EXP-010 is currently unallocated. Do not reuse EXP-009 confirmation to tune B. EXP-009's task distribution, dimensionality, feedback and endpoint differ from our persistent pair-memory assay, so cross-experiment mean differences are not causal contrasts.

## First concrete action

Write B's prospective development-only diagnostic protocol before any new outcomes. Use frozen direct PN, native sparse, calibrated sparse and appropriate degree/contact-controlled random representations from the existing pipeline. Primary diagnostic question: **can a linear readout recover old-pair labels from held-out noisy observations after those labels are poorly expressed by the online learner?**

Match noisy training observations and label availability explicitly. Compare the current chosen-action delta learner with (1) an offline fitted linear readout and (2) a supervised online delta control given the same labels/observations as the offline model. The offline readout has privileged access unless that matching is implemented; it is an explanatory diagnostic, not an equal-budget competitor or a capacity upper bound. Select regularization/optimization only on development partitions. Demonstrate optimization convergence and include sign/nonnegativity constraints separately from raw feature information.

Measure clean/noisy separability, rank/conditioning where informative, final held-out pair preferences, and the change to each old pair's margin after each new update. Keep mean and worst-pair behavior, noise and acquisition. Normalize or match effective update scale when feature norms change. Different feedback access, repeated replay of old labels, batch fitting, constraints and task ordering must not be silently combined into a single causal label.

## At most two nominated explanations

1. **Baseline input normalization and residual compensation.** Per-cell incoming-weight normalization may already remove much of the imbalance addressed by the published model. Our bounded partial offsets may add little usable representation change. Start with the local raw-contact versus per-cell-normalized projection, holding cues, connectivity, K, amplitude, readout and data partitions fixed. Test the compensation procedure under both projection conventions. Because drive units change, specify offsets in dimensionless per-cell or declared common drive units, and fit each condition only on its own independent unlabeled calibration pool. Declare any normalization-dependent target/bound conversion before seeing outcomes. Use the existing bounded procedure first. If stronger equalization is needed as a diagnostic, predeclare one range and solver budget; do not search for a positive sign or call it physiological. This factor tests a normalization account; it does not fully reconstruct author APL dynamics.

2. **Readout update dynamics under matched supervision.** Our error-dependent delta updates can overwrite old margins. Author multiplicative depression accumulates nonnegative sufficient statistics and commutes over odor order for fixed activities. Compare this rule with delta only after matching labels, training observations and output decision conventions, while measuring scaling/norm effects. Changing order alone cannot create an ordering effect in the fixed-input author rule. Demonstrate that invariance as a validation fixture. If a supervised online control closes the offline gap, do not attribute the original gap solely to the optimizer: feedback access or replay may explain it.

These are ranked explanations, not discoveries. Graded versus fixed-amplitude outputs, noise, expansion ratio and inhibition remain background differences. Do not add them all as extra bridge factors. A full graded-to-top-K conversion is a separate architectural change, not an innocuous implementation detail.

## Connecting regimes without changing everything

Keep the EXP-009 author-parameter encoder as a fixed reference and validate a readout adapter on development data first. Cross only the nominated representation-normalization and readout-rule factors if the preliminary diagnostic is informative. A local 2x2 normalization-by-readout test can test the same explanation without pretending to interpolate the whole author model. For an actual author-model normalization manipulation, account explicitly for how per-cell scaling alters both excitatory drive and the global APL sum; simply normalizing W while reusing old thresholds is a destructive mismatched-scale intervention, not an interpretable normalization control. Refit any necessary encoder parameters on independent unlabeled development inputs with a bounded validated method before interpreting the factorial. If that cannot be validated within B's resource cap, retain the fixed author reference and limit the causal conclusion to our pipeline.

Do not launch a factorial merely because A passed. The information-versus-learning diagnostic determines which contrast deserves fresh confirmation. Freeze one explanation and one falsifiable prediction, settings and sample size after development and before independent confirmation. Example candidate (not yet selected): offline and matched-supervision readouts retain discriminable old cues while chosen-action sequential delta loses old-pair margins; a well-fitted offline model that also fails would falsify that simple learning-only account. For normalization: removing baseline normalization should create a predeclared additional benefit of compensation; absence of that interaction under a validated intervention would count against it.

Use measured local CPU caps, checkpoint recovery, independent task-block uncertainty and practical/precision gates. If B cannot supply a valid diagnostic and discriminating prediction, report the limitation and prepare Session D; do not force speculative Session C. Growth, new anatomy, evolution, paid resources and publication retain their existing entry conditions.
