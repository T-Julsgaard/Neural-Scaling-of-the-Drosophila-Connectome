# EXP-006 prospective protocol

Written 2026-09-14 before development or confirmation. Priority 2 only; no homeostasis, growth or transfer intervention in this experiment.

## Task and controls

Independent block is the inferential unit. Each block contains 16 conditions: loads 2/4/8/16, overlap 2/6, exposure 128 presentations per pair or 512 total divided equally. Each presentation offers two cues and updates only the chosen cue using its stochastic +1/-1 reward (preferred probability .8, other .2). Independent random preference per pair; no pair identifier supplied to experimental learners. All previous weights persist through acquisition and reversal. Probe all learned pairs after each block, with no rewards or updates: 64 noisy replicates per pair at sigma .1 and .3. Report expected preferred-choice probability, not reward rate or deterministic classification accuracy.

Each cue has ten of 40 binary inputs. All cues share a randomly selected core of exactly 2 or 6 inputs. Within each pair residual supports are disjoint, so intersection is exactly 2/6. Across pairs residual supports are random, so intersections are at least the core size, not exactly 2/6; save the complete matrix. Unique prototypes enforced. Expected across-pair intersection is s+(10-s)^2/(40-s). This clustered-cue task deliberately stresses similarity across memories as well as within a pair; it is not an isolated manipulation of within-pair similarity. Load uses nested cue prefixes, labels, training and probe streams. Reset only between complete condition sequences.

Reverse pairs 0,2,... after acquisition, 128 presentations each in ascending order. Probe every pair after the complete reversal phase; report reversed and unchanged performance separately. Reversal exposure is extra and recorded separately from acquisition. Forgetting is immediate post-acquisition probability minus final probability for each pair; signed differences retained. Memory age is measured in subsequent training blocks and presentations.

Native N73 K4/K6, direct PN (40 features), randomized N73 K4/K6, cue-identity oracle (validation control). Two nonnegative opponent weight vectors, initial .1, chosen-action delta rule as EXP-005. Sparse activity has total amplitude ten; direct input is the clipped noisy PN vector. Direct has 80 learned weights; sparse has 146; oracle uses 2L features (4L effective weights). Oracle alone receives true noiseless cue identity. No experimental arm receives extra reward information. Shared observations, potential rewards and choice uniforms; realized choices may differ.

Three independently randomized circuits per block shared between randomized K4/K6. Bipartite switches preserve PN/KC binary degrees and each KC's exact contact multiset (expressed as native normalized weights); require 40 accepted swaps per edge, record overlap at 10/20/30/40 sweeps. This diagnoses mixing effort, not proof of uniform sampling. Average circuit replicates within block before inference. Native and direct receive the same tasks once, not three pseudo-independent observations.

## Development and frozen confirmation

Six development blocks 100–105, fresh namespace 6006/stage=1. Every family gets eight candidates: eta .003333/.006667/.01/.015 crossed temperature .1/.2 (EXP-005 grid). One global setting per family selected on equal-weight mean of retention, new learning, noise retention, reversal, unchanged-after-reversal across all 16 conditions and blocks. Tie within 1e-12 selects first grid entry. No condition-specific tuning. Oracle same grid for task validation only. Freeze selected settings, source hashes, environment, source anatomy, and protocol before generating confirmation. Confirmation: 32 fixed independent blocks 1000–1031, stage=2. No sample extension or adaptive stopping for significance.

Four primary paired contrasts in constant-per-pair exposure: (1) K6-K4 retention at load16/overlap6; (2) K6-K4 noise retention there; (3) K6 retention load16-load2 at overlap6; (4) K6 retention overlap6-overlap2 at load16. Bonferroni 98.75% two-sided percentile intervals using 20,000 deterministic block bootstrap draws. Other profile/contrast intervals are descriptive 95%. Report randomized and direct comparisons at each condition, without confirmatory superiority claims from pointwise intervals.

Capacity is the largest tested load for which every tested load up to it has simultaneous lower bounds strictly above .80 retention and .80 immediate new learning. Use one-sided Bonferroni bounds across 5 experimental families x 2 similarities x 2 exposures x 4 loads x 2 endpoints = 160 checks, familywise 95%; 200,000 block bootstrap draws. Also report descriptive profiles because conservative bounds can be imprecise. Capacity is qualified only at sigma .1; noise tolerance reported separately. If load2 fails, state 'no tested load certified', never capacity zero. Development precision assessment records estimated primary interval halfwidth and capacity proximity; no target precision guarantee. Fixed 32-block local budget; inconclusive results remain inconclusive.

## Execution and validation

Preflight covers overlap, unique cues, independent labels, exposure counts and stream pairing; weights persist at boundaries; probes do not update; scalar/batch and deterministic replay; degree/contact preservation; oracle independence from irrelevant noisy inputs; metric definitions. Source and data checksums freeze before each stage. Each condition saves complete per-pair probe histories, reversal probes, weight endpoints/boundary hashes, input and representation overlaps, participation and stability. Checkpoint after each block; checksummed resume, one validation block replay and one completed block replay per stage. Stop on nonfinite weights, invalid input/audit, source drift, >2 GB output or resource failure. No paid compute. Record environment, peak memory, wall/CPU time. Use a measured validation pilot for local runtime estimate. Saved arrays, not hand-transcribed metrics, drive results.

Scientific scope: stochastic synthetic paired discrimination in one static larval projection with sequential readout learning. Chen et al., https://pubmed.ncbi.nlm.nih.gov/41844155/, motivates similar-cue stress but is not reproduced by this model. Representation failure cannot be uniquely separated from readout interference or optimization by this benchmark alone. Subsequent homeostasis remains a separately frozen milestone.
