## Choice and scope

One task family only: binary exclusive-or (XOR) classification of two compound components, with continuous strength variation and nuisance features. The same second component predicts opposite labels depending on the first component. Learn first-component context 0, then context 1; both phases contain both labels. This tests conditional discrimination and generalization to fresh continuous/noisy observations, unlike random rewards assigned to unique cue pairs. There are no cue-ID inputs. It does not test unseen logical quadrants, abstract rule extrapolation or natural sensory data. Do not choose another task if this one fails.

Each independent block permutes 40 input channels into four five-channel component bundles and 20 nuisance channels; randomly reverses phase order and output polarity. A sample activates one bundle per factor with independent uniform [.6,1] strengths, two randomly selected nuisance channels with uniform [.1,.3] strengths, then adds clipped Gaussian noise SD .05. Training has 128 examples per phase, balanced second-factor labels and randomly ordered within phase. Evaluation: 512 fresh balanced examples per phase at .05 noise and 512 at .2. These are fresh observations and nuisance compositions; all four logical factor combinations occur in training. Seed namespace 11011, separate stage/block/component streams. No confirmation stream is generated during validation/development.

## Frozen encoders and learning

Reuse B's archived normalized 40-to-73 projections, top-K6 encoder and fixed strength-.25 offsets from EXP-007; no calibration on C data. Native, calibrated, three fixed degree/contact-controlled randomized encoders, direct input, and a generic all-degree-two polynomial direct-input diagnostic (constant, linear, all pair products including squares). Null instances are averaged within block; inference is conditional on this anatomy and these nulls. Polynomial is a capable diagnostic, not an anatomical performance claim. Scale direct and polynomial features by training-only mean squared norm to 100/6; sparse norms already equal 100/6.

Full deterministic +/-1 labels for every observation in every arm. No unchosen-feedback difference. Online uses B's two nonnegative readouts initialized .1 each, clipped delta updates; unclipped variant is diagnostic. All readouts include no additional bias except polynomial's constant (sparse fixed sum already supplies an intercept). Ridge fits signed coefficients on exactly the same 256 labeled observations; no evaluation inputs or labels used to fit. Offline has simultaneous stored-data access, different objective/solver and computation: explanatory diagnostic, neither equal-budget competitor nor capacity upper bound.

Schedules: blocked one-pass; unclipped blocked one-pass; shuffled one-pass; local10 (ten passes of phase 0 before ten of phase 1); replay10 (ten complete blocked passes through both phases). Every repeated pass uses exactly archived observations/labels, no new data. Shuffled one-pass holds observations, update count and rule fixed but requires all data available together and storage; local10 adds 10x updates and phase-local storage without revisiting old context after the switch; replay10 adds 10x updates and full-history access. These are schedule/access controls, not a new learning rule. No practical deployability or equal-memory claim. Save boundary weights and held-out acquisition/final scores; probes never change updates.
